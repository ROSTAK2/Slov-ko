# Slovíčko 🇸🇰

Приложение для iPhone, чтобы учить словацкий с нуля до B2 на русском языке. Упор на работу, учёбу и переезд.

## Что внутри

- **Курс:** 40 разделов (A1 → B2), 120 уроков, около 960 слов, теория на русском к каждому разделу.
- **Уроки в игровом формате:** выбор перевода, пары, сборка фразы из слов, диктант, ввод текста, пропуск в предложении. Есть сердца, опыт, дневная цель и серия дней.
- **Напоминания:** в выбранное время и вечернее «спаси серию» в 21:30, если вы ещё не занимались.
- **Озвучка** встроенным словацким голосом iPhone, медленный режим.
- **Карточки** с интервальным повторением и личный словарь.
- **ИИ-репетитор** (нужен ваш ключ Anthropic API): разговорные сценарии (собеседование, совещание, аренда, иностранная полиция…), разбор ошибок, новые уроки на любую тему.

## Как установить на iPhone (без Mac)

Нужны бесплатный аккаунт GitHub и AltStore на iPhone.

1. Создайте новый репозиторий на github.com (можно приватный).
2. Загрузите в него **все** файлы проекта, включая папку `.github` (кнопка *Add file → Upload files*; папку `.github` проще залить через GitHub Desktop).
3. Откройте вкладку **Actions**. Сборка запустится сама после загрузки в ветку `main` (или нажмите *Run workflow*). Она идёт около 5–10 минут.
4. Когда сборка зелёная, откройте на iPhone страницу **Releases** вашего репозитория и скачайте `Slovicko.ipa`.
5. В AltStore: **My Apps → «+»** → выберите скачанный `Slovicko.ipa`.

> Бесплатный аккаунт Apple позволяет AltStore держать приложение 7 дней. Затем AltStore продлевает его сам, когда iPhone и компьютер с AltServer в одной сети Wi-Fi.

Если сборка упала, откройте лог шага с красным крестиком и пришлите ошибку — её можно исправить.

## Советы

- **Голос:** для естественного произношения скачайте улучшенный голос: *Настройки → Универсальный доступ → Устный контент → Голоса → Словацкий → Laura (улучшенный)*.
- **Клавиатура:** в упражнениях есть строка словацких букв. Можно также добавить словацкую клавиатуру в настройках iPhone.
- **ИИ-репетитор:** получите ключ на console.anthropic.com (оплата по факту использования) и вставьте его в *Профиль → ИИ-репетитор*. Ключ хранится только на телефоне.

## Как менять курс

Уроки лежат в простых текстовых файлах в папке `content/`:

```
# 41 | B2 | Название раздела | Описание по-русски
> Теория (можно **жирный**)
## Название урока
w slovo | слово
s Celá veta. | Целое предложение.
f Veta s ___ medzerou. | odpoveď | zlá, zlé, zlý | Перевод предложения.
```

Перед сборкой GitHub сам запускает `tools/build_course.py`, который проверяет файлы и создаёт `App/Resources/course.json`. Локально:

```bash
python tools/build_course.py
```

## Структура

- `App/` — исходный код на SwiftUI (iOS 16+)
- `content/` — тексты курса
- `tools/` — скрипты сборки курса и иконки
- `project.yml` — описание проекта для XcodeGen
- `.github/workflows/build-ipa.yml` — сборка `.ipa` на GitHub
